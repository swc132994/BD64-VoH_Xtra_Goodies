Xtra Goodies is an optional addon for Brutal Doom 64: Veteran of Hell that introduces a selection of new weapons, ammunition types and power-ups designed to help players combat the tougher monsters and harsher encounters found throughout Veteran of Hell. The add-on expands the available combat options with additional firepower, utility and survivability upgrades while remaining fully compatible with the main mod's gameplay.
